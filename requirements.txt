After that to start run
python -m uvicorn main:app --reload
then, go here to see the server running
http://127.0.0.1:8000/docs#

make sure you have your own postgres database_url and create a secret key like this in 
a .env file

DATABASE_URL=username+psycopg://postgres:yourpassword@localhost:5432/databasename
SESSION_SECRET=create a random secret key look online
